# 仿真

有三种方式仿真 wallerobot，用的都是同一个生成出来的模型：

| | 在哪里 | 需要什么 |
|---|---|---|
| **网页模拟器** | {site}`sim/` | 浏览器（手机也可以） |
| **MuJoCo 查看器** | `projects/sim_mirror/scripts/view.py` | `requirements-model.txt` |
| **虚实镜像** | `projects/sim_mirror/scripts/mirror.py` | 真机（只读）+ LeRobot |

```{tip}
脖子还有一个单独的展示网站 **LeRobotNeck**（{site}`网站 <./>`）：{site}`脖子模拟器 <play/>` 只有脖子，演示可以暂停并调整姿态；{site}`爆炸图 <neck/>`
讲一条标准 SO101 机械臂加一个新连杆和 XLeRobot 的软指夹爪固定爪，怎样变成这个脖子。它的模型是 `hardware/variants/lerobotneck.yaml`
这个变体（竖塔 + 脖子，没有机身和手臂）。
```

## 为什么要主动感知

{site}`主动感知页面 <why/>` 在模拟器的桌面场景里比较六种相机装法。六种都用同一个 D435i 相机模型，都装在竖塔的同一个位置：

| 装法 | 自由度 | 能看到场景的比例 | 能做到的指定视角（共 80 个） | ……且画面不歪 | 画面被自己挡住 |
|---|---|---|---|---|---|
| 固定相机（XLeRobot 头部，电机不动） | 0 | 22 % | 0 | 0 | 0 % |
| XLeRobot 两轴头（左右转 + 上下点头） | 2 | 73 % | 0 | 0 | 3 % |
| 标准 SO101 + 装在 XLeRobot 腕部相机位置的相机 | 5 | 98 % | 32 | 16 | 13 % |
| SO101-X：标准 SO101，相机支架换掉活动夹爪 | 6 | 99 % | 58 | 45 | 15 % |
| LeRobotNeck | 6 | 94 % | 56 | 40 | 1 % |
| LeRobotNeck-02（设想）：J3–J4 连杆加长 7.4 cm | 6 | 98 % | 68 | 39 | 0 % |

比较的结论：

- **让相机移动。** 原地转动相机能看到空旷的桌面，但看不到东西后面和里面（方块背面的贴纸、盒子里面）。只有让相机本身移动的装法才看得到。
- **第六个关节。** 某个地方看到过一次，不等于能拍到指定的画面（相机放在这里，看那里）。这一点最关键的是第六个关节（相机俯仰）。SO101-X 用夹爪电机来做这个关节，不需要新零件。
- **标准固定夹爪。** SO101-X 留着标准固定夹爪，平均挡住 15% 的画面。LeRobotNeck 在这个位置换成了 XLeRobot 软指夹爪的固定爪。
- **连杆长度。** LeRobotNeck 看到的比标准手臂稍少，因为它的 J3–J4 连杆更短。设想中的 LeRobotNeck-02 把连杆加长到和标准小臂一样长，补上了这个差距。

页面上每种装法有自己颜色的点云，还会重播覆盖最多的 10 个视角。

**数字是怎么算的。** 数字由 `projects/web_sim/scripts/make_coverage.py` 算出。在 `make_neck_routes.py` 之后运行，大约 3 分钟，输出到 `web/public/why/`。

- **看得到的点：** 要同时满足：在画面里、距离 0.10–1.5 米、朝向相机（和法线夹角小于 80°）。到它的射线还不能碰到别的东西：桌面、物体、竖塔和这种装法自己的活动部件都会挡住，相机自己的外壳不算。
- **姿态：** 两轴头按左右、上下每 2° 取一个；四种手臂各取 30,000 个随机关节姿态，都不碰桌面、物体和竖塔。
- **指定视角：** 在桌面上方 12–32 cm 取 80 个相机位置，每个看向桌面上的一个点。用逆运动学从 12 个随机起点求解，位置误差不超过 1.5 cm、朝向误差不超过 3°，而且视线没被挡住，才算做到。"不歪"还要求地平线倾斜不超过 5°。

局限：只是仿真。LeRobotNeck-02 是设想，加长的部分画成一个方块。SO101-X 的俯仰范围借用脖子相机支架的范围，没有在真件上检查。没有考虑电机力矩。

## 网页模拟器

MuJoCo 3.16 以 WebAssembly 的形式在网页里运行，画面由 three.js 绘制。它是纯仿真，不会向外发送任何数据，也从不连接硬件。

**操作方式**
- **键盘**：沿 x、y、z 移动每条臂的夹爪，调整手腕俯仰和横滚，开合夹爪。脖子有单独的按键。按 `?` 可以看到完整的按键表。

  | | 左臂 | 右臂 |
  |---|---|---|
  | 前 / 后 | W / S | I / K |
  | 左 / 右 | A / D | J / L |
  | 上 / 下 | Q / E | U / O |
  | 手腕俯仰 | R / F | Y / H |
  | 手腕旋转 | Z / C | N / M |
  | 夹爪 | V | B |

  其他按键：
  - 脖子：←/→ 转头（J1），↑/↓ 相机俯仰（J6）；
  - 单个关节：`[` / `]` 选关节，`,` / `.` 转动它；
  - `G` 准备姿势，`X` 回 home，空格播放 / 暂停路线。
- **鼠标**：
  - 点一个部件，就选中它的关节；
  - 点手臂，夹爪上会出现三轴拖动手柄，逆运动学会跟着手柄走；
  - 也可以直接输入以毫米为单位的 xyz 目标。
- **路线**：
  - 自带几条固定示范：脖子、双臂、"看着手"；路点之间用最小加加速度曲线插值。
  - 也可以一个姿态一个姿态地录制自己的路线，然后播放、保存，或者导入 JSON 路线。
- **相机小窗**：显示脖子上 D435i 看到的画面（垂直视场角 43.2°）。

关于物理和逆运动学：
- 重力补偿模拟真机舵机那种很硬的位置保持。
- 逆运动学用阻尼最小二乘法，目标是两个指尖之间的中点。
- 求解时让肘部保持弯曲，避免手臂穿过奇异点时翻转。

## MuJoCo 查看器（Python）

```bash
python projects/sim_mirror/scripts/view.py                 # 休息位，运动学模式（滑块就是关节角）
python projects/sim_mirror/scripts/view.py --pose zero     # 所有关节为 0
python projects/sim_mirror/scripts/view.py --physics       # 跑物理，使用位置执行器
python projects/sim_mirror/scripts/view.py --collision     # 显示碰撞凸包
python projects/sim_mirror/scripts/view.py --snapshot x.png   # 不开窗口：输出 4 个视角加脖子相机的图
```

`projects/sim_mirror/scripts/sim_robot.py` 里的 `SimWallerobot` 提供一个类似插件的 Python 接口，方便脚本和策略调用：`get_observation()`、`send_action()`、相机图像。

## 虚实镜像（只读）

`mirror.py` 以大约 70 Hz 读取真机的 18 个编码器，让模型摆成同样的姿态。窗口上排是真实相机画面，下排是同一关节状态下的仿真画面。

它只**读**寄存器，并检查扭矩始终是关着的，所以接上一台新机器人时，最适合先运行它。可以用它来验证标定：用手转动一个关节，模型应该朝同一个方向跟着动。

```bash
python projects/sim_mirror/scripts/mirror.py --left-wrist 0 --right-wrist 2
```
