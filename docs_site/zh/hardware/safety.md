# 安全规则

这些规则来自参考机的调试过程，大多遵守起来很容易，踩坑的代价却很高。

## 上扭矩之前
- **上电后，`Goal_Position`、`Goal_Speed`、`Acceleration` 都读 0。** 这时直接上扭矩，等于让舵机全速开到 tick 0。正确顺序是：
  1. 写入目标 = 当前位置，以及速度上限和加速度；
  2. 读回确认；
  3. 再上扭矩。
- **写 `Goal_Position` 会自动打开扭矩**，即使目标就等于当前位置也一样。所以先写速度上限、加速度和力矩上限，最后才写目标。
- 上扭矩后先保持不动大约 1 秒，确认没有关节漂移；如果有，立刻放松扭矩。

## 运动中
- **脖子和手臂的 J2、J3 在折叠姿态下都靠在机械限位上**，超出了标定的限位。不要再往限位方向发指令。回位时用 `home` 姿态里被钳制过的 `target_ticks`。
- 运行新的策略或脚本时，保持设置 `max_relative_target`（插件选项）。
- 大动作要慢。参考脚本用的是 8–15 °/s。
- 跟踪误差过大或过载时要冻结；冻结后关节还在动，就放松扭矩。

## 结束时
- **一定要放松扭矩。** `robot.disconnect()` 会做这件事。脖子示范脚本会在 3 秒内把力矩上限逐渐降到 0，让 J2 和 J3 轻轻落回限位。

## 参考机上还没解决的问题
- 脖子 J6 的舵机一上扭矩，就会开往一个错误的目标，所以一直保持放松。原因还不清楚。
- 脖子 J4 的舵机重新装配后，`Present_Position` 读数总是多 4096。读取时按 mod 4096 处理；在查清楚之前，这个关节保持放松。
- 手臂还没有驱动过。原因见[](calibration.md)里关于编码器跳变的警告。
