# Robot model

The URDF, the MuJoCo model and the browser model are all **generated** from one configuration file,
{repo}`hardware/wallerobot_v0_1/robot.yaml`, together with
the calibration files and the vendored upstream XLeRobot URDF and meshes.

```{toctree}
:maxdepth: 1

config
customize
build
```

## Files

| file | what it is |
|---|---|
| `hardware/wallerobot_v0_1/urdf/wallerobot_static.urdf` + `meshes/` | full robot URDF: 18 revolute joints, visual meshes, convex-hull collision meshes |
| `hardware/neck_v0_1/urdf/wallerobot_neck.urdf` | the neck on its own (with the body) |
| `projects/sim_mirror/models/wallerobot_static.xml` | MuJoCo model: 18 position actuators, cameras `neck_color`, `left_wrist`, `right_wrist`, jaw tip sites |
| `projects/sim_mirror/models/scene.xml` | the model on a desk plane, with lights |
| `projects/web_sim/web/public/model/` | browser copy: referenced meshes, IK target sites `left_ee`/`right_ee`, `poses.json` |
| `hardware/wallerobot_v0_1/JOINTS.md` | the joint table below |

## Modelling choices

| item | how it is modelled |
|---|---|
| arms | upstream XLeRobot SO101 chains (joint frames, axes, limits, inertias); limits are intersected with the calibrated motor range |
| neck J1–J3, J4–J6 wrist | upstream SO101 frames; the new J3→J4 link from its STL (two measured points + orientation flags in `robot.yaml`) |
| collision | convex hull of every visual mesh (coarse); upstream convex parts for the jaws; pairs that already touch in the folded rest pose are excluded |
| drives (MJCF) | position actuators kp 20 N·m/rad, ±3.35 N·m, joint damping 1, armature 0.01 |
| inertia | arms from upstream; neck placeholders (0.05 kg per link) |
| cameras | D435i colour 640×480, vertical FOV 43.2° (measured intrinsics); wrist cameras 60° (estimated) |
